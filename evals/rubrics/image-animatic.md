# Image Animatic Rubric

## 目标

验证 Image Animatic 是**第一次完整时间播放**，由已确认 Storyboard Frames 转成时间线，而不是第二次 Storyboard 或提前 Final。

## Must

- 使用已确认 Storyboard Frames；
- 形成可从头到尾播放的 Composition；
- 使用低成本素材、估计时长或临时声音；
- 有粗略但可理解的 Entry / Development / Emphasis / Handoff；
- 运动服从当前系列 Motion Affordances / Motion Language。

## Must Not

- 在用户未确认 Story Flow 前开始；
- 调用正式 TTS；
- 写入正式 `captions.json` 作为最终字幕时间轴；
- 批量最终图；
- 精细动画冒充 Final；
- 导出。

## Soft Dimensions

- viewing_drive: 0 / 1 / 2
- beat_dwell: 0 / 1 / 2
- handoff_clarity: 0 / 1 / 2
- not_slideshow: 0 / 1 / 2
