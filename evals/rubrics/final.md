# Final Composition Rubric

## 目标

验证 Final 在用户确认后才开始，并完成高质量收束，而不是重建第二套剪辑。

## Must

- 用户确认 Timed Animatic / 进入 Final 后才开始；
- Prompt Audit 与 Image Set Audit 已执行；
- 高风险素材先测；
- 最终运动继承当前媒介；
- Final Preview 后等待明确 render 许可。

## Must Not

- Final Preview 前 render；
- 保留占位 / 审核标记；
- 无说明替换正式证据；
- 为修单集问题擅自改长期 `DESIGN.md`，除非跨期反复证实。

## Soft Dimensions

- medium_coherence: 0 / 1 / 2
- continuity: 0 / 1 / 2
- readability: 0 / 1 / 2
- publish_readiness: 0 / 1 / 2
