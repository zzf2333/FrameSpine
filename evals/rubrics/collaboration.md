# Collaboration Rubric

## 目标

验证 Agent 与用户的协作边界：阶段停止、交接清晰、反馈回到正确权威位置。

## Must

- 每阶段交付匹配 surface 的真实预览；
- 展示后停止，等待后续消息授权；
- 交接说明完成工作、风险、用户判断重点、确认后下一步；
- 普通制作动作不频繁微审批；
- 实质偏离才单独候选预览。

## Must Not

- 用户确认前跨阶段；
- 让用户充当第一轮 QA；
- 把多个权威位置同时改一遍修同一个问题；
- 把用户模糊反馈翻译成错误层级。

## Soft Dimensions

- handoff_clarity: 0 / 1 / 2
- stop_accuracy: 0 / 1 / 2
- root_cause_routing: 0 / 1 / 2
- preview_scope_discipline: 0 / 1 / 2
