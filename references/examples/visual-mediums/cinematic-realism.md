# Visual Medium Recipe：电影写实｜Cinematic Realism

> 这是 `Visual Expression Contract` 怎样填入具体配方的示例，不是 FrameSpine Core 的默认值，也不创建另一条制作流程。

## Visual Medium

以观察到的摄影世界呈现：人物、物件、空间和证据看起来受同一现实的时间、重力、使用关系与光线影响。

Visual Medium 不决定 Narrative Mode。本示例只演示这种媒介在造型、材质、空间、连续性和运动上的具体配方；它可以服务任何 Narrative Contract，但必须让该契约的 Meaning Anchor 可见。

## Form & Edge Language

人物保留稳定身份与自然比例；物件边缘、遮挡和焦点关系来自空间位置，不把主体抠成海报。避免磨皮、商品级摆放和所有人面对相机表演情绪。

## Framing & Viewpoint Language

观察方式可以是近景、肩后、局部特写或宽景，但由图片角色决定：证据用清楚的局部可读区域，过程用动作中间态，处境图显示人物与环境的关系。不要把每张素材变成同一侧面中景或浅景深英雄照。

## Material & Surface Logic

皮肤、织物、纸张、屏幕、桌面和日常物件有相应的表面差异。普通光线、反光、轻微磨损、使用痕迹和合理杂物只在确实服务叙事时出现。精确文字、数字和界面由 HyperFrames 叠加。

## Space & Depth Model

真实尺度、透视、前中后景遮挡和人物/物件的使用关系成立；为安全裁切和所需的慢推、平移或分层保留空间。

## Continuity System

人物通过身份特征、服装或状态线索保持一致；空间通过尺度、物件位置、使用关系和时间状态保持一致；证据始终保留可追踪的来源与语境。允许的变化必须来自故事中的动作、时间或结果，而非随机换脸、换物或换空间。

## Controlled Irregularity

允许自然裁切、轻微不对称、折痕、磨损和未完成状态；不允许畸形手、身份漂移、空间矛盾、对象数量失控或关键证据不可读。

## Motion Affordances

从可分离的前景、主体、背景、手部动作或局部证据中进行克制 reveal、push-in、pull-back 和 Handoff；运动揭示新关系，而不是替代图片叙事。

## Visual Variety

场景建立使用人物、空间与关系的完整可读画面；证据使用可验证的局部或文件语境；过程使用动作中间态；情绪使用身体、环境与停顿关系；回报回到已建立世界，重新解释同一人物、物件或空间的变化。观察距离、方向与构图随角色变化，而不重复单一英雄照。

## Medium Failure Modes

- 广告人像、样板房和过度布光；
- 统一暖灰滤镜、过度浅景深和每张都是“电影感”英雄构图；
- 以悲伤表情代替可见选择、过程或后果；
- 用生成的精确 UI / 文字充当证据。

## 同一素材任务的 Prompt 片段

```text
Make six months of repeated job applications with almost no response physically visible. In the established lived-in apartment workspace, the same person revises a resume while a generic application list and accumulated paper versions show repetition; exact UI text will be added in HyperFrames. Use a restrained over-the-shoulder view with room for subtitles and a later pull-back. Preserve believable object spacing, ordinary window light, worn paper edges and an unfinished working state. Avoid posed sadness, showroom styling, glossy skin and generated UI text.
```
