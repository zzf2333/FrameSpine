# 视觉媒介配方示例

这些文件展示系列实例怎样为同一套媒介中立 `Visual Expression Contract` 填入具体配方：

- `cinematic-realism.md`
- `manga.md`
- `paper-cut.md`

它们不是 Core 默认值，不是新的模式分支，也不替代 `SERIES.md`、`DESIGN.md`、`STORYBOARD.md`、Prompt Audit、Image Set Audit 或既有 Studio 预览边界。

同一内容可以在不同系列媒介中生产：图片角色决定叙事任务；视觉媒介决定造型、表面、空间与运动如何完成该任务。

这些示例不是 Visual Medium 的枚举，也不要求新系列选择最接近的一项。遇到黏土、木刻、拼贴、低多边形或混合媒介时，直接从 `Visual Expression Contract` 的类别生成新配方，不要先归类成电影、漫画或剪纸。

用户明确选择某媒介时，只按需读取最接近的一个示例；不要默认读取全部示例，也不要把多个示例拼接成新配方，除非用户明确选择混合媒介。
