# Visual Medium Recipe：黑白漫画｜Manga

> 这是 `Visual Expression Contract` 怎样填入具体配方的示例，不是 FrameSpine Core 的默认值，也不创建另一条制作流程。

## Visual Medium

以黑白漫画的阅读与叙事规则呈现人物、过程、证据和因果；不能只给摄影图套“manga style”标签。

Visual Medium 不决定 Narrative Mode。本示例只演示这种媒介在造型、材质、空间、连续性和运动上的具体配方；它可以服务任何 Narrative Contract，但必须让该契约的 Meaning Anchor 可见。

## Form & Edge Language

人物设定、比例、发型、服装标记和关键物件轮廓稳定。轮廓线粗细、黑白面积、速度线和留白有明确角色；环境可简化，但不能让人物、物件和证据失去辨识。

## Framing & Viewpoint Language

用连续构图、单格关系、局部特写、远近景切换和阅读方向控制发现顺序。证据可固定构图并放大关键局部；机制可通过可读路径、分格或层级逐步展开。不是每张都模仿摄影镜头或角色海报。

## Material & Surface Logic

墨线、网点、阴影块、留白和纸面颗粒遵循统一规则。黑白对比服务阅读层级，不随机添加彩色电影光。精确文字、数据和字幕由 HyperFrames 叠加，分格不应与字幕阅读冲突。

## Space & Depth Model

空间可采用透视、平面压缩、分格或象征留白，但同一段内使用一致的深度与阅读规则。人物与物件的比例、位置和连续动作必须可追踪。

## Continuity System

角色通过发型轮廓、服装标记、脸部比例和关键物件保持一致；环境可以简化，但阅读方向、人物位置和动作接力不能漂移。分格、黑白面积与网点规则在同一段中稳定，除非有明确的叙事转换。

## Controlled Irregularity

允许手绘线条轻微波动、网点密度变化和纸面不均；不允许角色变脸、线条体系突然改变、2D / 3D 混杂或让装饰纹理遮住证据。

## Motion Affordances

适合分格打开、局部重墨、速度线延伸、黑白面积 reveal、连续构图 Handoff 与面板式切换。运动应延续阅读顺序，不把静态漫画强行做成摄影机漂移。

## Visual Variety

场景建立使用完整空间格；证据使用局部特写；过程使用连续构图；情绪使用留白和黑白面积；回报使用已建立构图的重新解释。景别、分格密度、黑白比例与阅读速度随图片角色变化，不把每张都做成角色海报。

## Medium Failure Modes

- 真实照片只加漫画滤镜；
- 人物在相邻素材中失去设定一致性；
- 网点、阴影和线条没有规则，只为显得“日漫”；
- 2D 人物、3D 物件和写实摄影背景无意义混杂。

## 同一素材任务的 Prompt 片段

```text
Show six months of repeated job applications with almost no response through a stable black-and-white manga character and a sequence-like desk composition. First read: the character revises a resume. Second discovery: paper versions, empty reply marks and repeated application panels accumulate without progress. Use consistent ink contours, controlled screentone shadows, readable negative space for subtitles, and a rightward visual path for a later panel handoff. Avoid photorealistic lighting, 3D render surfaces, random anime decorations and generated text.
```
