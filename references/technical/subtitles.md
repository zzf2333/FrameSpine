# 技术附录：中英文双语字幕

字幕是基础语言同步功能，不是本 Skill 的核心创意竞争力。

固定要求：

- 中文旁白对应中文字幕；
- 同一语义组提供自然英文字幕；
- 中文为主层，英文为副层；
- 字幕始终不承担图片本应完成的视觉叙事；
- 字幕之外的编辑文字遵守系列的克制规则。

## 推荐流程

1. 完成正式中文旁白；
2. 使用火山 TTS 生成 `assets/audio/narration.wav`；
3. 使用 HyperFrames CLI 转写实际音频：

```bash
npx hyperframes transcribe ../assets/audio/narration.wav
```

4. 按自然中文短语拆分字幕组；
5. 为每组生成自然英文翻译；
6. 使用 HyperFrames captions reference 实现；
7. 在真实播放中检查阅读、换行与主体遮挡。

## 时间与分组

- 以正式音频为时间来源；
- 一次只显示一个字幕组；
- 中文和英文共享语义区间，但分别换行；
- 遇到长英文时优先自然改写，不机械缩到极小字号；
- 每组结束后按 HyperFrames captions 规则确定性隐藏。

## 视觉层级

一般建议：

```text
中文字幕：更大、更亮、主要阅读层
英文字幕：更小、更弱、辅助阅读层
```

具体字体、颜色和位置来自系列 `DESIGN.md`。

## 构图

双语字幕会占较多垂直空间，因此从图片节拍开始就考虑：

- 字幕安全区；
- 人脸、手、产品和证据保护；
- 图片推拉后是否进入字幕区；
- 平台 UI；
- 最长字幕组的真实高度。

不要等 Final 才把字幕压在图片上。

## 翻译

英文字幕追求相同语义和自然表达，不要求逐字对应。

保持统一：

- 人名；
- 品牌；
- 专有名词；
- 数字和单位；
- 语气；
- 重要概念。

## 动画

字幕动画应稳定、清楚，不抢图片：

- 轻微进入；
- 必要的词级高亮；
- 少量关键词颜色或尺度变化；
- 避免每组不同效果。

实现时读取 HyperFrames captions、typography 和必要的 dynamic caption references。

## 审片

检查：

- 是否漏字幕；
- 中英文意思是否一致；
- 是否跟随正式声音；
- 是否来不及读；
- 换行是否自然；
- 是否遮挡关键主体；
- 英文是否过度占画面。

这些是基础可用性检查，不是创意审批。
