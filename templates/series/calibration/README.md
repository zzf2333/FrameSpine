# HyperFrames 系列风格校准

这里的 composition 是**动态视觉身份测试**，不是一条 Episode，也不应伪装成即将发布的视频。

在此目录初始化 HyperFrames：

```bash
npx hyperframes init . --non-interactive
```

使用非叙事化的素材、抽象关系、通用占位文案或组件演示，测试配方能否稳定生产：

- 主体、物件、符号与视觉世界的连续性；
- 场景、证据、过程、机制、情绪与回报等图片角色的一致性与差异；
- 截图、文件、对象或 HyperFrames 精确文字的证据可读性；
- 当前媒介的造型、表面、空间、竖屏构图与双语字幕安全区；
- 当前媒介允许的运动、转场与 HyperFrames 承载方式；
- TTS 声线、节奏和音乐方向；
- 可复用的 HyperFrames 组件；
- Provider 在已确认能力内的稳定性与常见失败模式；
- Narrative Contract 在视觉世界中的一致性。

校准不是“好不好看”的投票：它要回答这套配方能否稳定生产十期内容。不要评分或建立通过状态；未解决的生产假设写回 `CALIBRATION.md` 的 Future Decisions。

不测试：

- 某个选题；
- 某一期 Hook；
- 某一期故事结构；
- 某一期图片节拍；
- 某一期 HyperFrames 镜头。

校准反馈只更新 `SERIES.md` 和 `DESIGN.md`。当用户提供具体内容时，在 `episodes/` 中创建单集并走 Episode Production。
