# 系列工作区

1. Agent 阅读 `references/core/series-initialization.md`。
2. 先分析用户已有资料，不重复提问。
3. 使用推荐先行、一次一问的收敛式共创。
4. 达到 calibration-ready 后停止追问。
5. 将系列目的、观众承诺、注意力与图片语言、Narrative Contract 和制作约束整理到 `SERIES.md`。
6. 在 `CALIBRATION.md` 中定义校准片要回答的 1–3 个高影响问题，并测试叙事契约是否被正确体验。
7. 将视觉身份编译到 `DESIGN.md`。
8. 复制 `.env.example` 为 `.env` 并填写 Provider 配置。
9. 在 `calibration/` 使用 HyperFrames 制作真实内容校准片。
10. 用户通过实际播放反馈后，更新系列基线并创建第一期。
